Overview

Scripts and notes for installing /e/OS 4.4.1 (Android 16) on a OnePlus Nord AC2001 (avicii) from Linux, then rooting it with Magisk v31.1. The flash itself is done by the official /e/OS factory image and its installer script, run unchanged. The scripts here handle the work the official guide leaves to the user: verifying downloads, proving the right phone is attached, auditing the installer before it runs, and refusing to flash when something does not match.

Problem / Motivation

Unlocking the bootloader and flashing erase the phone. A wrong image, a truncated 2.1 GB download or a second attached device can leave a phone unbootable. Every step that can be checked without touching the phone is checked on the laptop first, and the one destructive step needs an explicit confirmation tied to the device serial.

Implementation

  • Downloads (dl-worker.sh, start-downloads.sh). A resumable curl -C - loop with exponential back-off, capped at 300 s, started as systemd user units. A file gets its final name only after its size and SHA-256 match the published values.
  • Device checks (01, 02, 04). Read-only adb shell getprop checks: the model and serial match config.env; stock Android 12 (SDK 31); an official user/release-keys build; battery above 50%; OEM unlocking enabled; no accounts signed in. Every script stops if a phone listed in PROTECTED_SERIALS is connected.
  • Installer audit (05-prepare-eos-flash.sh). Unzips into a staging folder, checks that flash_avicii_factory.sh and factory.common are byte-identical to the audited copies, and confirms every image the installer names is present. It evaluates only the installer's image-list assignments, not the script, and prints exactly what will be written to which slots.
  • Guarded flash (06-flash-eos.sh --erase-and-flash). Requires the prepare step's marker file, exactly one device in fastboot, getvar product matching the expected platform, unlocked=yes and a clean update-merge state. Then the user must type ERASE <serial> before the official installer runs, with output logged.

Pinned versions and hashes live in one file (scripts/lib.sh). Everything the scripts write is git-ignored.

Results / Validation

On 30 Oct 2026, earlier versions of these scripts installed /e/OS on an AC2001 (India) running OxygenOS 12.1. The official installer took about three minutes and the phone booted into /e/OS. The published versions were generalised afterwards (serial in config.env, a protected-phones list, the --erase-and-flash flag). The laptop-side scripts were tested again after that; steps 01, 02 and 06 have not been run against a phone since.

Limitations

  • Covers one device model and one /e/OS build. Moving to a new build means updating the pinned URL, size and hashes and re-reading the new installer.
  • The India model receives EU (AC2003) firmware from the /e/OS package. /e/OS lists the AC2001 as supported, but no official source covers rollback protection across regions. The firmware check prints this as a warning.
  • Not official /e/OS or Magisk software.
