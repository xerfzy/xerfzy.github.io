Disclosure summary. Describes a system of drones carrying stereo camera, LiDAR, IMU and GPS sensors, with onboard SLAM, peer-to-peer links within the swarm, a centralised decision module, collaborative SLAM fusion, crowd-flow estimation, anomaly validation and failover when the central link is lost.

Related engineering work: Multi-UAV Monitoring Prototype. The linked prototype implements a simulated monitoring interface and ORB feature extraction only; it does not implement the swarm, SLAM fusion or crowd-analysis features described in the application.
